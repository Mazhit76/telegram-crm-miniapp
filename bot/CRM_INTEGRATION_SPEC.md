# Техническая спецификация Telegram Bot для CRM интеграции

## 🎯 Цель и назначение бота

### Основная цель
**AI-консультант для автоматизации лидогенерации и первичной квалификации клиентов IT-услуг**

### Бизнес-задачи
- Привлечение потенциальных клиентов через Telegram
- Автоматическая квалификация лидов с помощью AI
- Сбор детальных брифов на разработку
- Передача квалифицированных лидов в CRM
- Снижение нагрузки на менеджеров по продажам

## 🤖 Функциональность бота

### 1. AI Консультант
- **Технология**: OpenAI GPT-3.5-turbo (заглушки при отсутствии ключа)
- **Задачи**: 
  - Ответы на вопросы о услугах разработки
  - Консультации по технологиям
  - Предварительная оценка проектов
- **Триггеры лидогенерации**: "заказать", "разработка", "цена", "стоимость", "консультация"

### 2. Лидогенерация
- **Автоматическое создание обращений** при обнаружении ключевых слов
- **Уведомления клиентов** о передаче заявки менеджеру
- **Сбор контактной информации** (3 способа):
  - Кнопка "Поделиться контактом" (номер из профиля Telegram)
  - Автоматическое распознавание номеров в тексте
  - Ручной ввод в Mini App

### 3. Mini App (Детальный бриф)
- **Технология**: Vue.js 3 + Telegram WebApp API
- **Функции**:
  - Выбор типа приложения (13 категорий)
  - Сравнение с популярными аналогами (17 вариантов)
  - Технические требования (10 функций)
  - Бизнес-цели проекта (7 вариантов)
  - Загрузка файлов (до 5 файлов, 10MB каждый)
  - Контактная информация

### 4. Безопасность
- **Валидация входных данных** (SecurityValidator)
- **Защита от инъекций** (SQL, XSS, JavaScript)
- **Санитизация текста** и обработка Unicode
- **Ограничения по длине** сообщений (4000 символов)

- Валидация формата
- Сохранение в профиле клиента

## 📋 Техническая информация

### Технологический стек бота
- **Python 3.11+**
- **aiogram 3.4.1** (Telegram Bot API)
- **OpenAI API** (GPT-3.5-turbo)
- **httpx** (HTTP клиент для CRM API)
- **Vue.js 3** (Mini App)
- **Telegram WebApp API**

### Безопасность
- Валидация всех входящих данных
- Санитизация текста от XSS/SQL инъекций
- Ограничения по размеру файлов и сообщений
- JWT аутентификация с CRM

### Производительность
- Асинхронная обработка сообщений
- Кеширование токенов аутентификации
- Graceful обработка ошибок API
- HTTP таймауты 30 секунд
- Автоматическое переподключение при сбоях

### Сбор контактных данных
- **Telegram Contact API** - получение номера из профиля
- **RegEx парсинг** - распознавание номеров в тексте
- **Telegram Client Service** - управление клиентами в CRM
- **Автоматическое обновление** контактов при получении
